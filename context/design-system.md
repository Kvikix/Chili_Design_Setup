## Constraints
- Favor existing instances and variants over custom frames or detached components.
- Preserve Auto Layout, variable bindings, and semantic names when tooling supports this.
- Do not create library components or publish variables without approval.
- If a component/variant does not exist, flag the gap instead of improvising a new standard.
