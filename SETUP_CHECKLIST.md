- [ ] Project context reviewed by designer; no fabricated facts
- [ ] Project folders isolated; sensitive information excluded
- [ ] Jira task read confirmed (or pasted-text fallback)
- [ ] Figma approved frame read confirmed
- [ ] Design-system instance/variable read confirmed
- [ ] Figma draft page selected and permissions confirmed
- [ ] One small draft write tested after designer authorization
- [ ] `/feature-update` analyze mode tested on a real issue
- [ ] Build result checked against approved component and screen
- [ ] Named owner for updating context and shared skills
- [ ] Run time and correction time noted for the pilot
